================================================================================
0. NAME AND SCOPE
================================================================================
Adapt **only the essential** of Tinn-R_D's R workbar (`TBRMain`) onto the
plugin's native chrome (`chrome.py` / CudaText main toolbar).

STATghost stays the **receiver**. The plugin does **not** import Explorer,
Packages, Knitr, Rterm/Rgui/RHost, TCP, Plot, ls/str/print.

Umbrella: **WORKBAR**. Extension of VP-EB-1b, not a second chrome.

================================================================================
1. GOAL
================================================================================
 - Compact the bar: **nested** buttons for related tasks (TTBSubmenuItem
   pattern: Chunk, Workdir, Knitr, R start/close).
 - Parent click remains the classroom primary (Send / Source).
 - Do not clone TBRMain wholesale.
 - Icons: plugin already has tintable 16/24/32 (Flaticon). Tinn glyphs
   are 16px in `imlTinnR` (TPngImageList in the DFM) — extract the useful
   subset and generate 24/32 into the **stash** `w_todo/icons/` (plugin
   swap = VP-WB-2, not automatic: Tinn art is colour; current tint wants
   monochrome).

================================================================================
2. USER
================================================================================
Classroom: student writes in CudaText; sends selection/statement to
Armed STATghost. The plugin bar must fit beside Cuda's toolbar without
15 flat buttons. Send/Source extras belong in a **dropdown**, not only
behind Config.

================================================================================
3. MODEL (DECIDED for this first approach)
================================================================================
A) **Essential IN** (Tinn families the plugin already covers):

  | Tinn-R_D TBRMain              | Plugin                          |
  |-------------------------------|---------------------------------|
  | Echo (toggle)                 | OUT (collapse lives in Config)  |
  | Send File                     | Source (`.paths[4]`)            |
  | Send Selection / Smart        | Send (statement / selection)    |
  | Send Block / Contiguous / Line| OUT (Line already gone in EB-1) |
  | Cursor→BOL/EOL, line→top/EOF  | Above / Below (ranges)          |
  | Chunk prev/current/next       | **one** sniper chunk Send       |
  | Knitr / Sweave / Noweb        | OUT (not STATghost)             |
  | Workdir get/set/choose        | setwd (file directory)          |
  | ls / print / plot / str / fix | OUT → STATghost Explorer        |
  | Clear console                 | Clear (`#. STATGHOST:CLEAR`)    |
  | Graphics / remove objects     | OUT                             |
  | R start/close (Term/Gui/Host) | Start/Quit **STATghost**        |
  | Packages / TCP / completion   | OUT                             |

B) **Nests (Cuda toolbar)** — click = parent; arrow = children:

  Send▾    Function, Above, Below, Chunk
  Source▾  Src sel/fn, setwd

  Default top-level:
    Config | Arm/Idle | Start/Quit | Send▾ | Source▾ | Clear

C) **Side tab:** **expanded** list (captions; vertical room). Same ids /
   relative order. No arrow.

D) **Assign / pipe / Outline:** EB-1b extras, **not** on TBRMain. Stay
   opt-in flats (Config). Insert nest = VP-WB-3.

E) **Plugin icons (VP-WB-1):** keep `png/16px|24px|32px` tintable set.
   Tinn extracts → `w_todo/icons/` as reference / WB-2 candidate.
