plugins/ — CudaText peer plugins (VP-EB-1)
==========================================

cuda_statghost/  send selection / current line -> Armed STATghost
                 (clipboard UTF-8, layer B). Engine = active sniper.

Lab Linux (portable CudaText sibling):
  bash plugins/install_lab.sh
  # or: CUDA_ROOT=/path/to/CudaText bash plugins/install_lab.sh

Then restart CudaText. STATghost must be running and Armed.

Do not embed STATghost Console|Plot|Explorer UI here (D29).
VP-EB-1b (TOC / extra Tools) is a later VP — not this plugin.
